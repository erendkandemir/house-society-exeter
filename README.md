# House Society — Exeter

A first-pass Next.js landing site for House Society.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Before launch

Replace these placeholders in `app/page.tsx`:
- `hello@housesociety.example`
- HS001 date / venue / FIXR URL once confirmed
- membership signup/payment URL
- residents and committee names/photos

## Deploy

Push the folder to GitHub and import the repo into Vercel.
